# 26 章课后练习完整参考答案设计

- 状态：用户已明确要求补写，进入实施
- 日期：2026-08-24
- 范围：第 1—26 章正文中的全部复述题、识别题、实现/设计题和取舍题

## 目标

在保留现有《练习答案提示》作为快速自检入口的同时，新增一份可以逐题核对的完整参考答案。答案不能只给结论，必须展示判断依据，并明确设计题和取舍题可能存在多个合理答案。

## 文档结构

新增 `docs/appendices/课后练习完整参考答案.md`，按第 1—26 章排列。每章先链接原章，再按原题顺序作答：

```text
题目类型与原题摘要
→ 参考答案
→ 判断依据
→ 其他可接受答案或常见误区
→ 必要时给最小 TypeScript / SQL / Mermaid
```

复述题强调不用术语也能解释现象；识别题给具体观察点；实现题提供能表达核心边界的最小代码；取舍题同时说明“使用”和“不使用”方案分别在什么条件下成立。

## 内容约束

- 不把答案写成术语定义背诵。
- 不声称开放设计题只有唯一结构。
- 代码遵守现有 TypeScript 风格，不使用 `any`、非空断言或虚假的完整实现。
- 对正文明确省略的数据库、框架和生产设施，答案继续标明证据边界。
- 答案不得与可运行 `examples/task-api` 的实际能力冲突。

## 验收标准

- 覆盖 26 章中的全部课后题，不漏章节、不漏题号。
- 每道题至少包含参考答案和判断依据。
- 实现/设计题有代码、伪代码、SQL、表格或明确步骤中的至少一种。
- 取舍题说明适用与不适用条件。
- README 和学习路线同时提供“提示版”和“完整答案版”入口。
- `node scripts/verify-course.mjs`、Task API typecheck、test 和 build 通过。

## 非目标

- 不改写正文题目。
- 不把完整答案插进每章末尾。
- 不实现第 26 章描述但示例尚未具备的生产功能。
- 不初始化 Git 或创建提交。
