## 结果

第二章已经完成，并加入 README 的推荐阅读顺序。课程现在从第一章的“观察变化”推进到“判断模块知道什么、依赖什么，以及变化会沿哪个方向传播”。

本章新增的核心内容：

- 说明把代码移动到多个文件并不自动形成边界；
- 区分职责、依赖、依赖方向、耦合和内聚；
- 明确依赖方向是源码的知道、调用和 import 关系，不等于业务数据流向；
- 解释耦合不能只用 import 数量判断；
- 解释内聚不是代码物理上放在同一个文件；
- 使用 `unknown` 展示 HTTP 数据需要运行时收窄；
- 用 `readTitle`、`createTask` 和 `createTaskHandler` 建立三个最小边界；
- 使用窄的 `saveTask` 函数参数隔离保存动作，但不提前引入 Repository 类或依赖注入容器；
- 增加复述、依赖图、模块组织、运行时边界和抽象取舍练习。
